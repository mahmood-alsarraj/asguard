# Contributing to AsGuard

Thank you for your interest in AsGuard! We appreciate your support in making AsGuard the best ASP.NET Core monitoring package.

AsGuard is a **source-available** project rather than traditional open source. While our source code is viewable and we welcome community feedback, documentation improvements, and bug reports, we manage direct code modifications closely to maintain project quality, security, and licensing alignment.

---

## How to Contribute

### 1. Ask Questions & Get Help 💬
For general questions, configuration assistance, or setup issues, please use **GitHub Discussions** instead of opening an issue.
- Browse existing topics or start a new one in the **Discussions** tab.
- This helps keep the issue tracker focused on actionable bugs and feature requests.

### 2. Report Bugs 🐛
If you encounter unexpected behavior or errors:
1. Search existing issues to see if the bug has already been reported.
2. If not, open a new issue using the **Bug Report** template.
3. Be sure to provide a minimal reproduction code snippet and detail your environment (.NET version, AsGuard version, and database provider).

### 3. Suggest Features ✨
We are always looking to improve AsGuard! If you have ideas for new features or enhancements:
1. Search existing issues and discussions to see if the feature has already been proposed.
2. If not, open a new issue using the **Feature Request** template.
3. Describe the problem you are facing, your proposed solution, and any alternative workarounds.

### 4. Improve Documentation 📚
High-quality documentation is vital. If you find typos, outdated examples, or want to expand our docs:
- You are welcome to submit a Pull Request (PR) directly for changes under the `docs/` folder or the main `README.md`.
- Keep documentation edits clear, concise, and accurate.

### 5. Code Contributions 💻
Because AsGuard is source-available and maintains specific licensing, we ask that you **do not submit unsolicited code Pull Requests** for new features or major refactors without prior discussion.
- If you would like to submit a code contribution (such as a bug fix):
  1. Open an issue first to discuss the problem and your planned fix.
  2. Once aligned, you can submit a PR.
  3. Ensure your code follows the existing style guidelines, includes appropriate tests, and builds cleanly.
- By contributing code to AsGuard, you agree to license your contribution under the project's standard licensing terms.

---

## Code of Conduct

We are committed to fostering a welcoming, respectful, and collaborative environment. Please be respectful, supportive, and constructive in all discussions, issues, and pull requests.
